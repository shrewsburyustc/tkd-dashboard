Q21 · An edit that is undone: what does the Daily report show?

Found by the Black Belt session’s review of 0026. Example: the desk takes $290.00 cash. An admin edits it to $300.00 card, then clicks Undo on the “Payment changed” message. Undo after an edit saves a second edit back to the old values (not a delete), so the money is $290.00 cash again. Today Finance shows any edited payment as Edited. The totals and “Changed after closing” are right either way; only the line’s tag and note differ.
