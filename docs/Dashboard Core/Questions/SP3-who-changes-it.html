Side panel for the Grandmaster

Question 3: who changes a person’s panel size — each person, you, or both?

Decided so far: one choice per person, Standard · Large · Largest. A new person or device starts on Standard. Who changes it decides where it lives, and whether it needs a database change. The pictures are the preview (fake data), with the new row, item and box put on the real page. Amber box = what’s new.

Each person, in their own account menu

A “Panel size” row under their initials, next to “This device” and “Hide private details”.

  • Works like “This device”, which already picks one of a few choices the same way.
  • Can be built with no database change (how it’s remembered is the next question).
  • Anyone can change their own size when they want.
  • To set his, he must be signed in: you’d do it sitting with him — once, or once on each device he uses if it’s remembered per device (the next question).
  • He may not look under his initials himself; the design review noted that.

You, for each person, in Staff accounts

“Panel size…” in each person’s ⋯ menu opens a small box with the three sizes. This also settles how it’s remembered: with each account, in the database.

  • You set his from your own sign-in, without him; he never has to find it.
  • Saved with his account in the database: a migration (its number from Main), its security review, and you pasting it into Supabase.
  • Nobody changes their own size, only admins, here.

Both

Each person in their menu, and you for anyone in Staff accounts. Also saved with each account, in the database, including a person’s own choice.

  • Each person changes their own, and you can set anyone’s.
  • The same migration and security review as “You”.
  • Two places to build and keep in step.

Whichever you pick: at the main desk everyone signs in as “Staff” (the shared desk login, rulebook v0.27), so the desk has one size for everyone; his own size reaches him only where he signs in as himself. Phones have no side panel, so the row is left out of the phone’s menu. Step 2 (not started yet) will redesign both the account menu and Staff accounts, so either place gets designed again with it.

Recommendation: each person, in their own account menu. It copies “This device”, needs no database change, and you can set his with him. If you’d rather set it for him without him, choose both.
