Side panel for the Grandmaster

Question 4 (the last): how should each person’s panel size be remembered — on each device, or with their account?

Decided: one size per person — Standard · Large · Largest — changed by each person in their own account menu (“Panel size”, under “This device”). A new person or device starts on Standard. This question is only how the choice is kept. Pictures: what the Grandmaster would see, using question 1’s pictures. Amber box = the Large panel.

On each device

Saved in that device’s browser, for the person signed in — like Prospects’ List/Board choice and Calendar’s Show menu (rulebook v0.613).

  • Works like the two personal settings the app already has.
  • Each device can differ, for example Large on the desk PC and Standard on a tablet.
  • Picked once on each device he uses. A new device, another browser or cleared browser data starts on Standard.
  • An iPad can drop a site’s saved settings after about 7 days without a visit (rulebook v0.253), so a tablet unused for a week may go back to Standard.

With his account

Saved with his sign-in, in Supabase’s own small store of settings for each person (no new table, no migration).

  • Picked once, it’s there on every device he signs in on, new ones included, and survives cleared browsers. When an iPad clears a site’s data, he has to sign in again anyway, and his size comes back with that sign-in.
  • No database change for you to paste into Supabase.
  • New for the app: the first setting kept there. Each person can change their own copy, so it may only ever hold display choices like this one, never anything about who can see or do what (nothing does today).
  • A change reaches his other devices the next time the dashboard opens there (or within about an hour if it stays open), not instantly.
  • Saving needs the internet: if it fails, the usual “couldn’t save” message shows. A save on the device can’t fail.

Either way: it isn’t written to the change log (a display choice, like “This device”). At the main desk the shared “Staff” login has one size for everyone. Phones don’t change.

Recommendation: with his account. He picks once (you can do it with him) and it’s there on every device, with no surprise resets and no migration. Choose “on each device” if you’d rather it work exactly like Prospects’ and Calendar’s settings.
