D4 · The two-school “Download QR code” button: its hidden name

In the Registration link box with two schools, each card has its own Download QR code (outlined in amber). Besides the words on screen, every button has a hidden name: screen readers say it, and voice control listens for it. M5 (v1.106) set it to “Download Worcester QR code”. The design review found that this breaks WCAG rule 2.5.3, “label in name” (level A; the rulebook aims for WCAG 2.2 AA, §4): the hidden name must contain the button's words in the same order, so a person using voice control can say what they see.

The button's words first, then the school

On screen“Download QR code”, as approved (no change)

Screen reader says“Download QR code, Worcester”

Voice controlSaying “Click Download QR code” works; it asks which of the two

  • Nothing you approved on screen changes
  • Meets rule 2.5.3
