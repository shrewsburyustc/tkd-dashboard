Question 2: what shape should the setting have — three sizes, or two switches?

Your answers: “B but make it a setting that I can change. For example, I dont need the icons that big but he might, so let us be able to change based on who is using the it.” and “Also allow for bigger icons as well.” My reading: a size setting for each person. For example, you could stay on Standard while he uses Large or Largest. Anyone can have a bigger panel. Who changes it — each person for themselves, or you for each person (for example in Staff accounts) — is decided together with where the setting lives, in a later question. A new person or a new device starts on Standard, so nothing changes until someone picks a bigger size. Phones don’t change. The pictures are Home in the preview (fake data), with each look put on the real page. Amber box = what changes from today.

Three sizes — one choice

Panel size: Standard · Large · Largest, the way a phone offers text sizes.

  • One thing to set, in plain words; each size only adds to the one before.
  • Three looks, all measured and checked in question 1.
  • No “bigger icons without names”: on PC, bigger icons always come with the names.

Two switches

Bigger names on/off and bigger icons on/off, each set separately.

  • Each part can be chosen on its own, including bigger icons with no names on PC.
  • Four looks to build and check instead of three. The fourth, “bigger icons” alone, is drawn below.
  • Two things to understand and set instead of one.

Either way: Largest (or “bigger icons”) needs a rulebook exception for 24 px icons, because the panel’s rule is 18–20 px. Largest also needs a window 556 px tall: on a 1366×768 laptop zoomed to 125%, Finance starts off-screen and the page scrolls a little. Large’s 14 px names need a rulebook row too.

Recommendation: three sizes. One “panel size” choice is easier for the Grandmaster to understand, and it covers both of your examples: names for him, and bigger icons if he needs them.
