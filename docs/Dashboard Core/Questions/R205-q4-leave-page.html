R2-05, question 4 · Leaving the page while an Undo waits

The example (Camps → Thanksgiving Camp in the preview): Zoe Park is withdrawn, and her Undo is pressed while another save is still running, so the toast says "Undoing…" and the Undo waits its turn (questions 1–3). Then the person leaves the page, here with Home in the rail. Today the toast goes with the page (the app clears it on every page change), and nothing says what became of the Undo. The wait lasts only as long as the other save: usually a second or two, longer on slow Wi-Fi.

What happens when someone leaves the page while an Undo waits?

A · Leave freely; the Undo still runs (my pick)

Nothing asks. The Undo runs as soon as the other save ends, as it would have on the page. If it saves, nothing more is said: back on the camp page, Zoe is on the roster. If it fails, the amber bar shows under the top bar of whatever page you're on (v1.128), naming what it was undoing and where: "Undo didn't save: “Zoe Park withdrawn” (Camps). Check the connection, then retry." Retry runs the Undo again from there; × closes it.

+ Nothing is lost, and nothing is in the way.
+ The same rule as question 3: an Undo you pressed always runs.
− The Undo's wait has to live in the app, not the page, so the shared helper is a little bigger; and the bar needs words that name the change and the section.
− No "Undone" if it works after you left: the toast went with the page.

B · Ask first, with the leave box

While an Undo waits, leaving the page asks first, in the shared box the grading pages use for results that aren't saved (v0.192, v1.008). Stay on this page (first, and focused) keeps you there to see it finish. Leave anyway drops the Undo: Zoe stays withdrawn and is restored by hand (⋯ → Restore). The action is blue: nothing is lost for good.

+ You see the result on the page itself.
+ Built from parts that already exist: the leave guard and the shared box.
− A box in the way for a wait that's usually a second or two. If the Undo finishes while it's open, the box goes and you're still on the page.
− Leave anyway loses the Undo.
