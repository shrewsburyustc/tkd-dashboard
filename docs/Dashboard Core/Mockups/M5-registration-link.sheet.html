M5 · The shared Registration link box — mockup

One box everywhere (rulebook v1.015): Copy link and Download QR code in every section, Print flyer where a section has one today; one or two school links. Real QR codes. Amber outline = what the shared box decides.

1One school link (Color Belt): Copy link, Download QR code and Print flyer. Download QR code is new for Color Belt and Star: it saves the picture for your own flyers as a 1024-pixel PNG (big enough to print; Camps’ size today), named like “November Children Testing - Worcester QR code.png”. Copy link has the first focus; a copy shows the toast “Link copied”. Phones: a full-screen page with the back arrow, no Close.

2Two school links (Star; Black Belt the same without Print): one card per school, side by side — one under the other on phones. Copy and Print name the school; Download QR code says it to screen readers (“Download Worcester QR code”), as picture 12e drew it.

3No flyer (Camps — Jeffrey makes camp flyers himself, v0.232; Black Belt too): Copy link and Download QR code only. One link can serve both schools (“Both schools · held at Worcester”).

4Black Belt: two links without a flyer, and one line of its own under the cards (the ?dan= hint). A section can add such a line; the box doesn't know what it says.

5If Download QR code or Copy link fails, the amber note shows inside the box, under the cards — where the person is looking — and stays until the box closes (v1.004). The two sentences are shared words: “Couldn't make the QR code picture. Try again.” and “Couldn't copy the link. Select the link and copy it yourself.” (Star's). Today Color Belt, Camps and Black Belt put copy failures in a bar on the page behind.
