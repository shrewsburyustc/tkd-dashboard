M3 · The shared Mark paid box

The same small box everywhere, as the design review decided (rulebook v1.001, picture 03, option C): the amount, Paid by preset to the family's choice with “They chose … on the form.”, then Mark paid $X. v1.001 asked for full PC / tablet / phone mockups before it is built — these are they. Amber outline = the shared box. Two details to OK: (a) “Mark paid $X” has the first focus, so Enter marks it paid with the preset choice (1); (b) with no choice on record nothing is preset, and the button stays gray with “Choose how they paid.” until one is picked (4). On phones it is the same small box under the button. Every state at all four sizes: M3-mark-paid-box.png.

3Camps opens the same box from its “Owes $15.50” tag, as today (v1.001: tag → box). The amount is what the section gives — here what a camper still owes, with cents written as the money rule says (“$15.50”, v1.026). The box never lets the amount be typed.

No choice on record — detail (b): the button waits for a choice

4No choice on record (e.g. added at the desk without one): nothing is preset, there's no hint, and Mark paid $50 stays gray (the approved unavailable look, still focusable) with the gray line “Choose how they paid.” until one is picked. Here the first focus goes on Cash, the first choice.

What changes for each section when it switches (later, in its own prompt): Color Belt's one-click Mark paid opens this box · Star's Record payment dialog becomes this box (a different amount or date is fixed afterwards with Edit payment, admins — v1.001) · Camps' box gains Paid by · Black Belt keeps its own dialog and uses only the Paid by field. The box only hands the section the chosen way to pay; saving it is each section's job, and Color Belt, Camps and Star each need a small database change for that in their own prompt — none in this step.
