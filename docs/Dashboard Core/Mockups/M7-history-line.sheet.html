M7 · The shared history line — mockup

Every person's summary ends with “History · N changes ›” (rulebook v1.010; picture 09b): a tap opens the list in place, newest first. Prospects' line, as the design review drew it. Amber outline = the shared line.

1As the summary opens: the last line is History · 3 changes › (picture 09b, Prospects' line). It is a button: a tap or Enter opens the list in place; screen readers hear “collapsed / expanded”. (The blue ring shows how it looks with keyboard focus; the summary doesn't open with focus on it.)

2Open: newest first — what changed, then when · who in Massachusetts time (“Oct 22 · Jeffrey Berg”). The section writes “what changed”; the line writes the date and the name the same way everywhere. A long list scrolls with the summary.

3Hide private details on: changes about money are left out of the count and the list, and one gray line says so — Star's words (v0.506). The summary's payment row already reads “Hidden on this tablet”.

4While it reads (usually a moment, while the summary opens): “History” with a gray “Loading…”, not yet a button.

5If it can't read: the shared amber bar with Retry stays under the line until it works or the summary closes (v1.004). Today Star shows “No changes recorded yet.” instead, which hides the problem.

6Nothing recorded yet (e.g. a person added before the section kept a history): the line stays, as plain text — History · no changes yet — with nothing to open.
