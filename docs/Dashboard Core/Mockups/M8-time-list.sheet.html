M8 · The shared time list — mockup

Star's list made shared (rulebook v1.019; picture 14b): every 5 minutes, AM/PM on every time, opening at the chosen time; the range is a setting. Amber outline = the shared list.

1Closed: the field shows the chosen time with AM/PM (“4:40 PM” can't be read as 4:40 in the morning). One Tab stop; ↓, Enter or Space opens it.

2Open: the list opens with the chosen time in the middle, tinted blue (Star's list). Every 5 minutes, so 4:20 and 6:50 fit. ↑ ↓ move, Enter chooses, Esc closes the list only; typing a number jumps to that hour (“6” → 6:00 AM, “6” again → 6:00 PM). A thin scroll bar shows there's more.

3Moving with the keyboard: the row the arrow keys are on gets the blue focus ring (rule §4 — today's dropdowns show only a faint gray there); the tinted row stays the current choice until Enter. Screen readers hear each time as it is reached.

4Nothing chosen yet: a gray “Choose a time”; the list opens at its first time. Finance's reminder (right, set to Off and open): Off first, then 11:00 AM–11:00 PM every 5 minutes — its own range, the same list (v1.019, v0.207). Finance's prompt widens its database check, which accepts 15-minute steps today.

5While the dialog saves, both fields are gray and can't open (the app's read-only look).

6With a problem, the section's amber words sit under the field (“The end time must be after the start time.”, today's words) and screen readers hear the field as invalid — never red, never color alone.
