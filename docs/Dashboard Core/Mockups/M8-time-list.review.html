M8 · The shared time list

One time list for every section, as the design review decided (rulebook v1.019, picture 14b): Star's list, every 5 minutes, AM/PM on every time, opening with the chosen time in the middle; 6:00 AM–10:00 PM for classes, testing and camps; Finance's reminder keeps Off and 11 AM–11 PM. The same list on every device — not the phone's own picker (v0.51). It is built on the shared dropdown (Star's, made shared, v1.100). Amber outline = what the shared list decides. Two details to OK: (a) the row the arrow keys are on gets the blue focus ring (3) — today's dropdowns show only a faint gray there; (b) typing a number jumps to that hour — “6” → 6:00 AM, “6” again → 6:00 PM (2). Every state at all four sizes: M8-time-list.png.

Closed

1Closed: the field shows the chosen time with AM/PM (“4:40 PM” can't be read as 4:40 in the morning). One Tab stop; ↓, Enter or Space opens it.

Open at the chosen time — detail (b): type a number to jump

2Open: the list opens with the chosen time in the middle, tinted blue (Star's list). Every 5 minutes, so 4:20 and 6:50 fit. ↑ ↓ move, Enter chooses, Esc closes the list only; typing a number jumps to that hour (“6” → 6:00 AM, “6” again → 6:00 PM). A thin scroll bar shows there's more.

Moving with the keyboard — detail (a): the blue focus ring

3Moving with the keyboard: the row the arrow keys are on gets the blue focus ring (rule §4 — today's dropdowns show only a faint gray there); the tinted row stays the current choice until Enter. Screen readers hear each time as it is reached.
