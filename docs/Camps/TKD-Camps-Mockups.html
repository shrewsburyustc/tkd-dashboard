C1. Camps list

Upcoming camps for the chosen school. Today is Sun, Oct 18, 2026.

Amber outline = new compared to Color Belt

What it does

  • New rail section Camps (ti-tent, after Home and Testing; the phone bar gets Home · Testing · Camps). Page title “Camps”, tabs Camps | Templates, header button + Add camp (N on PC).
  • Upcoming / Past switch with counts, like Color Belt’s Events tab. Columns: Camp · Dates (all days + how many) · Campers · Status · Edit + ⋯.
  • Status tag: Open until Nov 24 (green), Not open yet, Closed (sign-up closed before camp — by its date or by hand, e.g. Veterans Day Camp is full (proposal)), Camp today (on any camp day), Done (past) — the last four are neutral.
  • A camp is for Worcester, Shrewsbury or Both schools (held at one of them). On Worcester or Shrewsbury you see that school’s camps plus the both-schools camps, marked “Both schools · held at Worcester” under the name (April Vacation Camp). On Both a School column appears, reading “Both schools” for those (phone: a line on the card). Members of either school pay member prices at a both-schools camp.
  • ⋯ menu: Save as template (C2b) and Delete camp (red, asks first — not reversible).

How staff use it

  • Click a row to open the camp’s page and roster (C4). Edit opens the same dialog as Add camp (C3) filled in.

Notes

  • The brief’s April dates (Mon, Apr 20 – Fri, Apr 24, 2027) don’t match the calendar: Apr 20, 2027 is a Tuesday. Shown as Mon, Apr 19 – Fri, Apr 23, 2027 (Patriots’ Day week) — please confirm.
  • Delete camp with campers on it: same rule as Color Belt’s Delete event (warning, admin only) (proposal).
  • Icon map entries needed (rulebook 2.4) for the icons these Camps screens use that the map doesn’t list yet: ti-tent (Camps section), ti-template (Save as template (proposal)), ti-users (Campers card), ti-clock (Not paid card), ti-cash (Payments recorded card), ti-user-minus (Withdraw). The last four are already used by Color Belt’s roster.

C2. Templates tab

Reusable camp setups, shared by both schools. Use starts a new camp from one.

Amber outline = new compared to Color Belt

What it does

  • Lists the saved templates: name (exactly as typed when saved) · number of days and the lowest price (“from $75 (1 day, member early)”) · how many extras.
  • Use (small outline button) opens Add camp (C3) with “Start from” already set to that template — only the name, school and days are left to fill in.
  • ⋯ menu: Edit template (the same folded layout as Add camp, without days; renaming happens here too) and Delete template (red; asks first (proposal)). Deleting a template never changes camps made from it.
  • Templates are shared by both schools: the location switcher doesn’t filter this tab. The school is picked in Add camp.
  • Using a template and then picking fewer days drops the extra price-grid rows; picking more days adds empty rows to fill in (amber “Enter a price” until they are).
  • Empty state: one line, no button — templates are made from a camp (⋯ → Save as template), so there is no “Add template” here.

How staff use it

  • For a summer week: Templates → Summer week → Use → type the name, tap the 5 days → Save.

Notes

  • The page header keeps + Add camp on this tab, so there’s still one primary button and N still works.

C2b. Save as template

Small dialog from a camp’s ⋯ menu.

C3. Add camp — folded sections

Starting from the Vacation week template, for both schools. Only Camp is open; the rest are summed up in one line each.

Amber outline = new compared to Color Belt

What it does

  • Detail view: a wide (720px) centered dialog on PC and tablet; full screen with a back arrow on phones. At the top, Start from: Blank camp or a template (templates are shared by both schools).
  • Then five folded sections. Only 1. Camp is open at first: Camp name; School (Worcester | Shrewsbury | Both schools — when Both schools is chosen, Held at Worcester | Shrewsbury appears next to it (proposal)); and Days, a month calendar where you tap days on or off, summed up under it (“Mon, Apr 19 – Fri, Apr 23, 2027 · 5 days”).
  • Sections 2–5 are bordered rows with a number, a title, a one-line summary of what’s inside and a chevron (ti-chevron-down; the open one shows ti-chevron-up). Clicking a row opens it: 2. Times (camp hours in 5-minute steps, family sign-up opens / closes, early price until — prefilled from the template as days before camp, and changeable), 3. Prices (the grid: one row per number of days, last row “5 days (all days)”; second PC frame), 4. Extras (name · price · Once or Per day · “Not charged to all-days campers” · remove · + Add extra), 5. Family form (description — including what to bring — and waiver).
  • From a template most camps are: name + days + Save. Save works from anywhere; there is no Next / Back.
  • A section with a problem turns amber and shows what’s wrong in its summary (phone frame: “1 extra has no price”); pressing Save opens it. Choosing fewer or more days than the template drops or adds grid rows; the Prices summary then shows amber “1 row needs prices”.
  • Edit camp and Edit template use the same folded layout, so changing one price means opening just Prices.
  • A Both schools camp shows on the Worcester, Shrewsbury and Both lists, and members of either school pay member prices.

Notes

  • Selected days use the dark outline, not blue (rulebook row needed: multi-select day chips use the dark outline). School / Held at use the neutral segmented style for the same reason.
  • Phone calendar: no frame or gaps and 44px-tall day cells. At 320px wide the 7 columns are about 41px wide each, so a full 44×44 tap area needs the calendar to run almost edge to edge (6px sides) on the smallest phones.
  • The 3- and 4-day prices are examples. Example waiver wording is a placeholder (proposal).
  • Once a camp has campers, changing its days asks first if it would change anyone’s price (proposal).

C4. Camp page and roster

Shown during camp week (Mon, Apr 19, 2027), day filter on Monday.

Amber outline = new compared to Color Belt

What it does

  • Opening a camp shows its page: back link “Camps”, name, status tag, and one line with days · hours · school (here “Both schools · held at Worcester”) · camper count. Header: Registration link (ti-qrcode) is the one primary button — it opens the link / QR dialog (C5) — and ⋯ holds Edit camp, Save as template, Print roster (ti-printer) and Delete camp (red).
  • Campers only come in through the family form. A parent at the desk scans the QR code, or staff open the link on the desk tablet and hand it over. Staff fix mistakes with ⋯ → Edit details. There is no Add camper button.
  • Summary strip: Color Belt’s four cards — Campers · Paid · Not paid · Payments recorded. Rows that owe money count as Not paid. Each card opens the list behind it.
  • Day filter: All days | Mon 19 · 14 | Tue 20 · 16 | … Picking a day shows only the children coming that day; the line under it gives that day’s count and drop-off / pick-up numbers (“Mon, Apr 19 · 14 campers · 6 early drop-off · 4 late pick-up”) — the “who’s in the building today” list. During camp it starts on today (proposal); otherwise on All days. On phones it wraps into Color Belt’s 3-column grid (2 rows of 3, 44px cells) — no sideways scrolling.
  • Columns (PC): Camper (name, age, “non-member” when it applies — no date of birth, address or medical in the list) · Days (“All days” or “Mon, Tue, Wed”) · Extras · Paying by · Total · Status · actions. Tablet and phone put extras and paying by on a second line.
  • Status tag, same priority as Color Belt: Owes $15 (amber) > Paid (green) > Not paid (neutral gray). Owes appears when days or extras are added after paying; its button reads Mark paid $15 and records just the difference. Mark paid records the full amount in one click, the way the family said they’d pay, with a 5-second Undo toast.
  • Row ⋯ (Color Belt R8 wording): Change how they’ll pay, Edit details, Admin: Edit payment / Undo payment, then Withdraw and Delete permanently (red). Withdraw moves the camper to a Removed group at the bottom of the roster (Undo toast, then Restore); removed campers are not in the counts.

Notes

  • Mark paid keeps Color Belt’s built button (ti-check + “Mark paid”). Icon map entry Mark paid / Paid → ti-check to be recorded (exception already used by Color Belt; the map reserves ti-check for Save).
  • Payments recorded totals are example figures.

C5. Registration link

The camp’s family sign-up link and QR code. Every camper comes in through the family form.

Amber outline = new compared to Color Belt

What it does

  • Opened from Registration link on the camp page (C4). Based on Color Belt’s Registration link dialog (R2): the camp name, a line saying until when sign-up is open, then a card with the school (“Both schools · held at Worcester” for a both-schools camp; one link for both schools), the QR code, the short link and two small buttons. Close on PC and tablet; full screen with a back arrow on phones.
  • Copy link (ti-copy) copies the link and shows the toast “Link copied” (tablet frame).
  • Download QR code (ti-download, the map’s Export icon) saves the QR code as an image file the owner puts on his own flyer (proposal).
  • No Print flyer. Color Belt’s dialog has one; Camps deliberately doesn’t — the owner designs camp flyers outside the app.
