Question 3 — class times on an event

A Color Belt testing runs class by class (in October: Little Tiger and White first, then the groups). The family form shows each student’s time (“Group A tests at 5:00 PM”), and staff see the roster grouped by time on the day. How does an admin set those times when adding an event?

Decided 2026-10-17 (Jeffrey): A — a start and end time per class, copied from the last event.

A. A start and end time per class Recommended

“Classes testing” lists the school’s 7 classes, each with a tick box and a start → end time. Untick a class that isn’t testing (e.g. Teen/Adult has its own event). Classes with the same times test together. Copied from the last event.

  • Families see their child’s exact time: “Group A · 5:00 – 6:00 PM”.
  • Same as the old Color Belt system; the roster groups classes by time automatically.
  • Usually nothing to type — times copy from the last event.
  • The longest dialog of the three (7 rows).

B. One start time for the whole event

Exactly Star’s “Start time” (Star v0.69), plus tick boxes for which classes test.

  • Shortest dialog; same as Star.
  • Every family is told 4:00 PM, even if their child tests at 7:00 — long waits, or staff telling times by phone.
  • The roster can’t group by time.

C. Sessions (time slots with classes in them)

The admin adds sessions (“Session 1 · 4:00 – 5:00 PM”) and puts classes into each.

  • Reads like the day’s plan; a session can hold several classes.
  • An extra layer: add session → choose time → choose classes (more steps, its own dialog).
  • Gives the same result as A, which already groups classes with the same times.
Recommendation: A. It gives families their real time, matches how testing already runs, and copying from the last event means most events need no typing. C adds steps for the same result; B sends everyone at the first time.

What the family sees on the form (after choosing the class, question 2):

A: Group A tests at 5:00 – 6:00 PM  ·  B: Testing starts at 4:00 PM  ·  C: Group A tests in Session 2, 5:00 – 6:00 PM

Option A — a time per class (recommended)
