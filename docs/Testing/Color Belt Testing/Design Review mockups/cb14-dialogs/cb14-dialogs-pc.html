Rulebook v0.427 moves Classes and ranks to Settings and gives Color belt testing a Prices tab. Each field now lives in one place, so the dialogs split. These are the app's own dialogs with the fields taken out (real preview screenshots, fake data). Amber = what leaves a dialog today, green = what is new. One thing is undecided: what Add rank does about prices (bottom of this page).

Staff see the Prices list read-only: no pencils, so no dialogs. The tab shows each rank's Early, Testing day, Private and Sparring gear, and each class's final award on the class line.
The question: where does a new rank get its prices? The database needs all three prices when a rank is made. A (recommended): Add rank, which stays in Settings, keeps the price fields and Sparring gear, pre-filled from the rank above as today: one dialog, everything set at once, and nothing is guessed for you. B: Add rank has no prices; the new rank copies the rank above's prices and the toast says so ("LT Brown added with LT Black's prices. Change them in Prices."): a shorter dialog and the structure stays separate from the money, but a rank can go live with prices nobody looked at, and B has a hole: the first rank of a new class has no rank above to copy from, so the dialog would still need price fields there (or the rank would start at $0, which makes its testing free until someone notices). Either way the prices of an existing rank are only ever edited on the Prices tab.
