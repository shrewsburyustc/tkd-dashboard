What each piece does

  • Rail item (PC, mouse only): the Testing hover menu gets a third item, "Black Belt testing" (ti-award), under Star testing. It works like the other two: arrow keys move through the items, Enter opens, Esc closes. Staff and admins both see it.
  • "Next:" line: the earliest Black Belt testing day on or after today, from every cycle that isn't past (whether or not registration is open), always "· both schools" since a cycle is for both schools. A testing day that's today still counts (same as Color Belt and Star). No line at all when there's no upcoming day (no filler text, v0.177). The top-bar school switcher doesn't change it.
  • Address: every Black Belt page gets its own address, like Star's. Browser Back and Forward step between them (fixing today's "Forward reopens Color belt testing" gap from v0.516). Unsaved rubric changes still ask first before Back leaves the page (R10). An address for a deleted cycle opens the Cycles tab with the usual "this cycle was deleted" note. With the Star switch off, #testing/black-belt works the same, and Black Belt's "← Testing" goes back to Color Belt's page.
  • No database change. Only app files (navItems.js, pageAddress.js, App.jsx, the chooser files, Black Belt's page). Several are shared files, so this needs a merge with Star's branch afterwards.
