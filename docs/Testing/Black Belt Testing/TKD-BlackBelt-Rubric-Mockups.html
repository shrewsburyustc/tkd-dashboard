How admins change the Black Belt rubric — the parts, subjects, credits, scoring tables and pass marks — on the Rubric and prices tab (the default rubric every new cycle starts from) and on a cycle's new Rubric tab (that cycle's own copy, until its registration first opens). Built on the approved Cycles mockups (screens 4, 6 and 8) and the built Rubric and prices tab.

Already decided — drawn this way below

  1. v0.921 (Q1 = A): a default rubric on Rubric and prices, editable by admins any time, used by every new cycle; each cycle’s own copy is editable until its registration first opens, then locked (like prices, v0.902). A mistake found after opening goes into the default for next season. Staff see the rubric read-only.
  2. v0.922 (Q2 = A): everything inside the four fixed parts (Physical, Technical, Curriculum, Other requirements) per Dan: subjects (add, remove, rename, reorder), credits, the grade points of each part (A+ … D), measured subjects (unit, at least / at most / under, age groups and cut-offs), tags (outdoor, adults only, handed in, a note), the pass mark (children / adults) and the no-D rule, extra-point items and steps, part names, and Copy from another Dan. A part’s maximum is worked out, not typed. The database checks every value.
  3. v0.923 (Q3 = A): an admin edits a whole Dan and presses Save [Dan] once; changed rows tinted; a gray line counts the unsaved changes; Cancel throws them away; leaving with unsaved changes asks “Discard changes?”. Save checks the whole Dan and stores it in one step (one history entry); toast “1st Dan rubric saved” with Undo. If another admin saved meanwhile, Save says so instead of overwriting.
  4. v0.902: prices live only on each cycle and are set when it is saved; Rubric and prices keeps the waiver “and later the rubric”. v0.901 (a requirements sheet with no edit screen) is changed by v0.921.
  5. v0.210: admins edit Rubric and prices; staff view it (“View only. Ask an admin to make changes.”), enforced in the database.

R1. Rubric and prices with the default rubric (admin)

The second tab of Black Belt home. The Waiver and Keeping cards stay as built; the Default rubric card is new, below them. Drawn: 1st Dan, with Push-up’s cut-offs opened. Today: Mon, Feb 15, 2027.

What it does

  • Default rubric card (amber outline = new): a Dan switcher (1st–4th Dan), the gray line “Used by every new cycle. A cycle’s copy can be changed until its registration first opens.”, and Edit 1st Dan (admins; the label follows the Dan shown).
  • To pass line: 275 points (children) · 293 (adults) · no D in any subject, and the most points a candidate can score (339, adults 361.5) before extra points.
  • The four parts, each a card: name, worked-out maximum (Physical up to 80, Technical 44, Curriculum 135 / 157.5 adults, Other requirements 80), its grade points (A+ … D), and one row per subject: credits, scoring, tags (Outdoor, Adults only, Handed in, a note) and Up to (credits × the part’s A+ points). The foot says how the maximum is worked out.
  • Measured subjects (Stretching, Push-up, sprints…) show a Cut-offs toggle; opened, it shows the age-group table (Push-up: 8 and under / 9–12 / 13 and over, A+ … C).
  • Extra points (Extra stripes 1 point each; Competitions 1+ → 3 … 5+ → 15; Attendance 320+ → 3, 375+ → 5, 400+ → 10 …) and Handed in by Submissions due (Egg test, Meditation, Appreciation letter, TKD project).
  • “Last changed by Jeffrey B. · Feb 2, 2027” under the card.
  • Phones: the subject rows stack (name and tags, then “2 credits · up to 8 · count, at least”); the grade points become one line of text; nothing scrolls sideways at 320.

Rules applied

  • v0.921 — a default rubric on Rubric and prices, editable by admins any time, used by every new cycle; staff read-only.
  • v0.922 — the four parts stay; a part’s maximum is worked out from its subjects, not typed.
  • v0.902 — prices stay on each cycle (“Same for both schools. Prices are set on each cycle.”). v0.213 / OP-8 — Waiver and Keeping cards unchanged from the built screen.
  • 2.1 / 8 — compact 28px button with a mouse, 36px on touch; dense rows 36–40px (44px+ touch). 2.4 — ti-edit for Edit.

R3. Editing a Dan

Edit 1st Dan turns the card into the editor. Drawn after three changes: Sit-up renamed “Sit-up (30 sec)”, Push-up credits 2 → 3, children’s pass mark 275 → 279.

What it does

  • The whole Dan is edited at once (v0.923). The card head becomes an edit bar: “Editing 1st Dan · default rubric · 3 changes not saved”, Copy from another Dan, Cancel, Save 1st Dan. The bar sticks to the top while the page scrolls; the Dan switcher is hidden while editing (switching Dan would leave the draft, see R8).
  • Changed rows are tinted (light blue, the same tint as a selected row; amber stays for errors); the gray line counts the unsaved changes.
  • Live maximums: Physical “up to 80 → 84 points” as soon as Push-up becomes 3 credits; To pass shows “most points 339 → 343 (361.5 → 365.5 adults)”. Up to on the row: 8 → 12.
  • Per part: the part name (a field), the grade points A+ … D (fields; they must go down), then the subjects: grip to drag, name and credits typed in the row, the scoring and tags, Up to, Edit (opens the subject’s dialog, R4) and ⋯ (Move up, Move down, Remove subject — PC frame). + Add subject under each part with the part’s credit total.
  • To pass: children and adults points, “No D in any subject”. Extra points: R5. Handed in is worked out from the tags.
  • Nothing is stored until Save 1st Dan: Save checks the whole Dan (R6) and stores it in one step. Cancel throws the changes away and goes back to the read view.
  • Phones: the editor is a full-screen dialog (back arrow + “Edit 1st Dan”), with a footer that stays at the bottom: “3 changes not saved” and Save 1st Dan; Copy from another Dan at the top. Subject rows show name, tags, credits and scoring; tapping Edit opens the subject full screen (R4), where the name and credits are typed. At 320 nothing scrolls sideways (grade points wrap to two rows of five).

Rules applied

  • v0.923 — whole Dan, one Save [Dan], tinted rows, gray count, Cancel, “Discard changes?”, one history entry.
  • v0.922 — everything inside the four fixed parts is editable; maximums worked out; Copy from another Dan.
  • v0.43 — reorder by grip drag, plus Move up / Move down in ⋯ (as the Black Belt plans in Add cycle). 2.5 / 8 — touch rows 48px, max 2 visible row actions + ⋯ (Edit + ⋯).
  • 8 Forms — labels above fields, 32px fields (36px touch). v0.46 / v0.56 — full-screen dialog on phones with the back arrow.
