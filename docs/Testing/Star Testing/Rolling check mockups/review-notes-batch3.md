## Answer to the builder's open question (M-02 scope)
Keep M-02 joining every save, family-form registration included. Reasons: (a) Jeffrey approved the rule as "the rows of one save make one entry" (Pass 2 Fix-Star M-02, v1.055), and Camps and Star's own edit-of-several-fields already work that way; (b) the grouping key (same transaction time + same function name + same person) cannot join two different saves, so widening it costs no accuracy; (c) limiting it to money rows needs a second list of "which tables count" that must be kept in step with the database later, and would leave other multi-row saves (the make-up copy, withdraw) split; (d) Color Belt joins only money rows simply because its other saves write one row, so the two sections still read alike. The only visible effect is the repeated "on the family form" in the joined sentence (SHOULD 5); that is a words question for Dashboard core's R1-07 set, not a reason to narrow the rule.
