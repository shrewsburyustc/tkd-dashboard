## The three open questions

1. "in this Dan": keep it. It is true (the list is one Dan, `CandidatesTab.jsx:281`), it copies Color Belt's "in this class", and the Fix-Star item asks for Color Belt's pattern. Add the guard in SHOULD 1(a) so an empty Dan keeps "No candidates for this Dan."
2. Count pairs, not rows. The orange box right above says "1 possible duplicate" (`CandidatesTab.jsx:1523`, `dupCount(pairs.length)`), so the same number under the cards reads as one story. Counting rows would print "2" under a box that says "1". Black Belt does count rows and has that mismatch; do not copy it. To avoid understating, say what is left out: "1 possible duplicate isn't counted in Paid or Not paid until it's reviewed." is fine for one; for two or more consider "Both rows of each possible duplicate aren't counted…" only if Jeffrey wants more precision. State in the plan that Star deliberately differs from Black Belt (rows) and Camps (rows that still owe).
3. Two stacked gray lines: keep. The duplicate line is exactly what explains a missing Ava Reed while a filter is on, so hiding it then (Black Belt hides it on phones while a card is on, `SummaryCards.jsx:54`) would remove the explanation when it is needed most. Order (duplicate, then Showing, then the school line) matches `CountCards` and needs no shared-part change. The only crowded case is Worcester only plus a filter (three gray lines); the 320 frame shows it fits.
