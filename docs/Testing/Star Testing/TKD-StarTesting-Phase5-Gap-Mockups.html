Proposals to confirm (31)

  1. H1 · A grade or class count shows in the cell at once and saves in the background, one save per cell (star_set_grade / star_set_count, last save wins, v0.165). While the first save is on its way nothing extra shows; Total and Result change when the database answers (usually well under a second), because the screen never works a result out itself (v0.158). Screen readers hear “Saved”.
  2. H1 · A failed save keeps the chosen grade in the cell, which turns amber with a small ⚠; the row’s Result reads amber “⚠ Not saved · 2 grades” (text, never colour alone, §4). Total keeps the database’s last saved total (“—” while the row is incomplete) until the save goes through. A count box turns amber the same way (“Not saved · 1 count”).
  3. H1 · One page-level banner under the tabs, never auto-closing (rule 3.5), Color Belt’s live wording with “grades”: “Couldn’t save 2 grades (Noah Chen). Check the connection, then try again.” with Retry and ✕. With several it names up to three candidates, then “and N more”, and counts grades and counts separately. Dismissing it leaves the amber cells, which keep retrying.
  4. H1 · Not saved cells are sent again by themselves every 10 seconds and as soon as the browser says the connection is back (Color Belt v0.192); meanwhile the row’s Result reads gray “Saving…” and the cell stays amber until the save goes through. Retry sends them all now. Nothing is kept in the device’s storage (v0.188). Changing a Not saved cell again sends only the newest choice. Before any retry, the app compares the cell with its latest refreshed value; if someone else changed that cell since this device’s grade was chosen, the retry is dropped and the cell shows the other person’s grade with a gray note “Changed on another device — your grade wasn’t saved.” Why: the database keeps the last save (v0.165), so a mat tablet that was offline for ten minutes would otherwise overwrite the newer grade the desk typed in meanwhile.
  5. H1 · A Dan with Not saved cells gets an amber ⚠ in the Dan switch (as Color Belt’s class switch, v0.190), so a grader who moved to another Dan still sees it; the banner counts every Dan.
  6. H1 · Offline (the browser says so): the same banner, worded “You’re offline. 9 grades and 1 count aren’t saved yet. They save by themselves when the connection is back. Keep this page open.” with Retry. Grading goes on (each new grade joins the Not saved ones), the 15-second refresh waits, and a refresh never overwrites a Not saved cell. When the connection is back, a refresh runs before the retries, so the check in proposal 4 can drop any grade someone else changed meanwhile. No separate offline bar (Color Belt’s live Grading has none; rule 3.5’s bar isn’t built dashboard-wide).
  7. H1 · Leave guard (Color Belt v0.192, CONTRACT-0010 §4.9): leaving the event page while anything is Not saved (Back link, rail, bottom bar, browser Back, Sign out) asks first: “3 grades and 1 count aren’t saved” · “Mia Patel (Korean Terminology), Noah Chen (Breaking, Knowledge) and Ethan Lopez (Assistant classes) weren’t saved because the connection dropped. If you leave now, they’re lost. Stay, and they’ll save when the Wi-Fi is back.” · Leave anyway / Stay on this page (blue default: Enter, Esc, backdrop, Back). Reload or closing the tab: the browser’s own “Leave site?”.
  8. H1 · No question when switching Dan, switching to the Candidates tab or opening a private grading page of the same event: the saves belong to the event page and keep going. The lock screen doesn’t ask either; retries pause while locked and start again after the PIN (as Color Belt).
  9. H2 · Clicking or tapping a gray kept cell opens no dropdown; a small note opens under it: “Kept from Spring 2026 · A” / “Kept grades can’t be changed on this testing. To correct one, fix it on Spring 2026, then an admin removes this make-up and adds it again (if it’s still a make-up).” (OPEN-9; if the earlier result is no longer a make-up, star_add_makeup answers stale). It closes on a tap elsewhere or Esc. Phone: the kept line has no ▾ and reads “A kept”, with “kept from Spring 2026” under the subject; tapping shows the same note.
  10. H2 · A save answered kept (the grid was out of date): banner “That grade was kept from an earlier testing, so it can’t be changed here. Your change wasn’t saved.” with ✕ only; the cell goes back and the grid reloads. Never retried, never “Not saved”.
  11. H2 · A save answered stale because the candidate’s Dan was changed on another device (v0.164): banner “Jordan Kim was moved to 2nd Dan on another device.
