Star testing · Results tab — questions

Jae H. Jeong’s U.S. Taekwondo Center · Star testing, build phase 5 (Results, printouts and email) · guidelines v0.137 · October 17, 2026

The event page’s Results tab: each candidate’s total and result once grading is done, making a Dan’s results final (which locks grades for staff, v0.127), telling families, printing, and exporting. Known so far: pass = total ≥ 245 of 315 and no D; a D means a make-up of the D subjects (v0.96); below 245 with no D, an admin chooses the make-up subjects (v0.130); make-ups are added to the next event from a list (v0.111); results must never be ambiguous (always the reason, e.g. “Make-up · D in Breaking”); the dashboard has no email service yet.

Question 2 — How is a Dan’s results made final?

Answered 2026-10-17: none of these — results stay open

“It really never closes.” No final step or lock; class make-ups are updated on the same event; subject make-ups are handled case by case. Recorded in v0.139 (replaces v0.127’s lock).

Already decided: only admins make results final, one Dan at a time, and that locks the Dan’s grades for staff (v0.127). This decides what has to be done first and what happens to anyone not finished. Example: 1st Dan, where Sofia Reyes (make-up) hasn’t been graded in Korean Terminology yet.

Question 3 — How do families get their results?

Answered 2026-10-18: B now, A later

The school has no domain yet, so results open in the school’s own email for now; a sending service once there is a domain. Recorded in v0.140.

Results go out per candidate whenever each is ready (v0.139). Any message to families needs a confirmation first (rule 1.4). The dashboard has no email service today; sending email from it needs one set up (an outside service plus the school’s email domain; usually free or a few dollars a month at this size — to check when building).

Question 6 — Is there a CSV export, and what’s in it?

Answered 2026-10-18: Option B (changed from A)

Recorded in v0.144.

A CSV is a plain spreadsheet file the dashboard can save, for keeping records outside it or pasting into another system (the old prototype had one with Dan, name, age, school, email, fee, payment, classes, score, result). Any file with students’ personal details is sensitive once it leaves the dashboard (rule 5). Proposed: a Download CSV button beside the Dan switch, for the whole event or the selected Dan.
