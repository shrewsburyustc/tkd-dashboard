## Part C — Rulebook mismatches noticed in passing

- **Icon map is missing `ti-currency-dollar-off`.** It is used for Hide private details at src/components/AccountMenu.jsx:331 and src/components/TopBar.jsx:25, and decided in v0.215 (row at docs/Dashboard Docs/TKD-Dashboard-Design-Guidelines.md:667). §2.4 (docs/Dashboard Docs/TKD-Dashboard-Design-Guidelines.md:193) says icons go in the map before use. The status file (docs/Finance/TKD-Finance-Status.md:102) says to add it; that never happened.
- **`ti-calendar-event` means two things.** It is "Today" in the phone ⋯ (src/screens/finance/DayReport.jsx:469; drawn that way in D14, docs/Finance/TKD-Finance-DailyReport-Mockups.html:509). The map gives it a different meaning ("planned schedule note" / "Event", docs/Dashboard Docs/TKD-Dashboard-Design-Guidelines.md:135, 139). This breaks rule 2.3.
- **`ti-history` map row is out of date.** It says only "Past schedules (v0.233)" (docs/Dashboard Docs/TKD-Dashboard-Design-Guidelines.md:136); Finance's History also uses it (src/screens/finance/DayReport.jsx:470,525). v0.207 called it a shared meaning, but the map was not updated.
- **‹ › map row is out of date.** It says "Previous / next month or week" (docs/Dashboard Docs/TKD-Dashboard-Design-Guidelines.md:137); Finance uses ‹ › for days (src/screens/finance/DayReport.jsx:490-500).
- **Rule 1.4:** a reversible action should give a toast with Undo. "Day reopened…" has no Undo (src/screens/finance/DayReport.jsx:428). It was kept as built (docs/Finance/TKD-Finance-Status.md:103), but no 10b row records the exception.
- **Rule 8:** "Clicking a card opens the filtered list behind it" (docs/Dashboard Docs/TKD-Dashboard-Design-Guidelines.md:369). Finance cards scroll to the group instead (src/screens/finance/DayReport.jsx:436-441). D1 approved this, but it differs from the filtering cards in Color Belt and Star.
- **Rule 3.5 offline bar:** none in Finance. The grep found offline handling only in Star files.
- **§9 sections table is stale.** docs/Dashboard Docs/TKD-Dashboard-Design-Guidelines.md:391 still says Finance is "(designing) / Designing" and covers "Color belt testing now, Star testing once built". Finance has been live since 2026-10-19 (docs/Finance/TKD-Finance-Status.md:123) and now also includes camps and private testing.
- **v0.198 vs code:** v0.198 says a Both box has one tag, "Closed / Not closed yet". The code adds a third, "No payments" (src/screens/finance/BothSummary.jsx:29). It is not in the D6 drawing (docs/Finance/TKD-Finance-DailyReport-Mockups.html:382-389).
- **v0.707 vs CSV (needs checking).** v0.707 says the export's What = "Camp" and the event = the camp's name. src/lib/finance/csv.js:86-90 writes "Camp · <name>" into the For cell, and the date column is headed "Testing date" for camp rows too (src/lib/finance/csv.js:44).
- **D12 / v0.207:** "Open in Testing goes to the event's roster". Star payments still open the Testing section instead (src/App.jsx:892-894,911). CP1 (v0.801) accepted this because the Finance branch had no Star event route; Star is now on main.
- **§2.4 (docs/Dashboard Docs/TKD-Dashboard-Design-Guidelines.md:190)** says every "Payments recorded" card (including Camps and Black Belt) uses `ti-sum`. Camps has no cards (just a summary line, src/screens/camps/CampRoster.jsx:494-500), and Black Belt has no such card (src/blackBelt/staff/candidates/SummaryCards.jsx:18-21).
- **Rule 2.1:** full-width buttons are only for the single submit button of a phone form. The phone "Open in Testing" is full width (src/screens/finance/PaymentDetailDialog.jsx:122) but is not a submit button. It matches the D12 drawing.

**Biggest differences in how payments work across sections (all cited above):**
- **Method label:**
  - "Paying by" before paying.
  - "Paid by" for a recorded payment (Color Belt, Star, Camps, and Finance's detail and CSV).
  - "Method" in Black Belt (src/blackBelt/staff/text.js:747).
- **How money is shown:** Testing, Camps and Black Belt show "$65" (whole dollars); Finance always shows "$65.00" (src/screens/finance/format.js:17-21).
- **Undo payment:** Color Belt and Camps undo at once with no Undo; Star and Black Belt ask first, and their cancel buttons differ ("Keep payment" vs "Cancel").
- **Money handed back:** Star and Black Belt use "Record refund"; Camps uses Edit payment; Color Belt has none.
- **Date entry:** Star uses the shared DatePicker; Color Belt, Camps and Finance use native date fields; Black Belt has no date field.
- **Hide-switch wording:** shared "Hidden on this tablet" (src/lib/privateDetails.js:47) vs Black Belt "Hidden on this device" (src/blackBelt/staff/text.js:607). Black Belt imports Finance's old hook name `usePaymentsHidden`; Camps doesn't use the switch at all.
- **Choice controls:** Testing's ChoiceGroup is used by Finance and Camps; Black Belt has its own `Choice` (src/blackBelt/staff/candidates/dialogParts.jsx:61).
- **Errors inside dialogs:** Black Belt puts an ErrorBanner at the top of the dialog; Testing and Camps put a Notice in the footer; Finance puts the error above the button.
- **Not-paid card icon:** ti-clock in Color Belt, Star and Camps; ti-circle-x in Black Belt, which uses ti-clock for "Paying on schedule".
